# Журнал изменений

## [Unreleased]

### Добавлено

- Последовательный линейный решатель PETSc с выбором метода Крылова,
  предобуславливателя и допусков через параметры полного бассейнового расчёта.
- Переиспользование предобуславливателя AMG внутри геологической эпохи.
- Команда `tools/run_heat_forward.sh` для запуска подготовленных данных
  в Docker с одним вычислительным потоком.

### Изменено

- PETSc является обязательной зависимостью численного ядра.
- У линейного запроса заданы допуски и предел итераций по умолчанию.
