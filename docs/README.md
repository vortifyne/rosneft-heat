# Документация

Каталог содержит проектную документацию.

## Разделы

- [dev/](dev/README.md) — процесс разработки, дорожная карта, бэклог и заметки по задачам.
- [reference/](reference/README.md) — архитектура, математическая модель, численные методы и справочные материалы.
- [user/](user/README.md) — запуск приложения, входные данные, параметры командной строки и результаты.

## Основные документы

- [dev/development-process.md](dev/development-process.md) — правила разработки, инструменты, стиль кода и работа с задачами.
- [dev/roadmap.md](dev/roadmap.md) — крупные этапы разработки.
- [dev/backlog.md](dev/backlog.md) — актуальные и выполненные задачи.
- [reference/architecture-overview.md](reference/architecture-overview.md) — верхнеуровневая архитектура вычислительных компонентов.
- [reference/problem-statement/](reference/problem-statement/README.md) — исходная постановка задачи.
- [reference/drafts/](reference/drafts/README.md) — черновые справочные заметки.
