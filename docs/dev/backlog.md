# Бэклог

Документ содержит только незавершённые задачи. Крупные направления развития описаны в
[дорожной карте](roadmap.md).

## Приоритеты

- `P0` — задача необходима для выбора дальнейших решений;
- `P1` — важная задача основной линии;
- `P2` — улучшение, которое выполняется при подтверждённой необходимости.

## Основная линия

| ID | Приоритет | Задача | Результат |
| --- | --- | --- | --- |
| `MESH-004` | P0 | Устранить чрезмерно вытянутые и тонкие элементы сетки | Близкие координаты по горизонтали объединены, а выклинивания не создают элементов с миллиметровой поперечной толщиной. Выбранные ограничения качества зафиксированы и проверяются для всех конфигураций `data1` и `data2`. Полные расчёты сходятся без ухудшения глобального баланса энергии. |
| `TEST-006` | P0 | Подготовить воспроизводимую проверку сходимости полного расчёта | Описаны и автоматизированы серии расчётов `data1` со сгущением по пространству и времени. Решения сопоставляются в одинаковых физических точках, вычисляются оценки по правилу Рунге. Один запуск занимает не более 10–15 минут. |
| `PERF-003` | P0 | Измерить стоимость частей прямого расчёта | Отдельно измерено время движения сетки, вычисления свойств, сборки матрицы, линейного решения, EASY%Ro, переноса состояния и записи файлов. Накладные расходы измерений оценены. |
| `LIN-005` | P1 | Выбрать итерационный линейный решатель и предобуславливатель | На представительных матрицах сравнены GMRES, BiCGStab и подходящие предобуславливатели по времени, памяти, числу итераций и фактической невязке. Для выбранных матриц исследованы крайние сингулярные числа и характерная обусловленность. |
| `LIN-006` | P1 | Исследовать способы ускорения, использующие структуру матрицы | Проверены дефляция медленных мод и применимость методов Фурье. Для пригодных вариантов измерено ускорение полного прямого расчёта; непригодные варианты исключены с указанием причины. |
| `TIME-004` | P1 | Реализовать BDF2 | Схема поддерживает переменный шаг, начинает и восстанавливает историю через BDF1, корректно работает после перестроения сетки и подтверждает второй порядок на задаче с известным решением. |
| `TIME-005` | P1 | Реализовать управление шагом времени | Шаг выбирается по оценке временной ошибки, точно заканчивается на границах эпох и повторяется с уменьшением после несходимости. Отклонённая попытка не изменяет принятое состояние. |

## Отложенные улучшения

| ID | Приоритет | Задача | Результат |
| --- | --- | --- | --- |
| `NLS-003` | P2 | Реализовать метод Ньютона для полной задачи | Учтены производные теплофизических коэффициентов и потоков. Метод сопоставлен с методом Пикара по общему времени расчёта и надёжности сходимости. |
| `MESH-003` | P2 | Реализовать консервативный перенос состояния | Перенос сохраняет интегральную внутреннюю энергию прежнего материала и не ухудшает сходимость температуры при сгущении сетки. |

Задачи полной обратной постановки будут сформулированы после получения входных данных,
наблюдений и перечня калибруемых параметров.
