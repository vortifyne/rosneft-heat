# Задачи

`P1` — основные работы, `P2` — отложенные улучшения.

| Код | Приоритет | Задача |
| --- | --- | --- |
| `PERF-001` | P1 | Измерять время основных частей прямого расчёта, включая чтение и запись, без двойного счёта вложенных интервалов. Собирать числа итераций по шагам и суммарно. |
| `PERF-002` | P1 | Повторно использовать подготовленные данные, геометрию и сетки в обратной задаче. Определить зависимости от подбираемых параметров и измерить время и память повторных расчётов. |
| `LIN-005` | P1 | Сравнить GMRES, BiCGStab и предобуславливатели по времени, памяти, итерациям и невязке. Исследовать обусловленность матриц и влияние минимальной высоты ячейки. |
| `LIN-006` | P1 | Проверить ускорение с использованием структуры матрицы: дефляцию медленных мод и методы Фурье. Оценить выигрыш полного расчёта. |
| `TIME-004` | P1 | Добавить BDF2 с переменным шагом и восстановлением истории через BDF1 после перестроения сетки; подтвердить второй порядок. |
| `TIME-005` | P1 | Управлять шагом по оценке временной ошибки, точно попадать на границы эпох и повторять несошедшийся шаг с уменьшением. Отклонённая попытка сохраняет принятое состояние. |
| `NLS-003` | P2 | Реализовать метод Ньютона для бассейновой задачи и сравнить с методом Пикара по времени и сходимости. |
| `LIN-007` | P2 | Исследовать предобуславливатель на основе независимых трёхдиагональных систем по столбцам; сравнить с ILU/ILU2 и AMG. |
| `MESH-003` | P2 | Реализовать перенос, сохраняющий интегральную внутреннюю энергию прежнего материала и сходимость температуры при сгущении сетки. |

Для обратной задачи бассейна предстоит уточнить наблюдения и подбираемые параметры.
