# Бэклог

Документ содержит ближайшие задачи проекта. Дорожная карта верхнего уровня описана в [roadmap.md](roadmap.md).

## Приоритеты

- `P0` — задача блокирует ближайший этап или без неё нельзя двигаться по основной линии разработки.
- `P1` — важная задача, которую нужно сделать в рамках ближайшего этапа, но она не блокирует первые шаги.
- `P2` — полезная задача, которую можно отложить без остановки основной разработки.

## Исполнители

- `DD` — Д. Д.;
- `NS` — Н. С.;
- `TBD` — исполнитель ещё не назначен.
