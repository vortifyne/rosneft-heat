# Направления развития

Подробные и назначенные задачи находятся в [бэклоге](backlog.md). Этот документ фиксирует только
порядок крупных работ и не повторяет отдельные задачи.

## Прямой расчёт

Рабочая основа включает чтение геологической истории, послойную движущуюся сетку, метод конечных
объёмов, зависимые от температуры свойства, BDF1, метод Пикара, EASY%Ro и сохранение результатов.

Дальнейшие изменения прямого расчёта должны последовательно решать следующие вопросы:

1. поддерживать воспроизводимую основу сравнения на `data1` и проверять запуск `data2`;
2. улучшать точность переноса состояния, если глобальный баланс или проверка на известном решении
   покажут существенную ошибку;
3. добавить управление шагом времени и BDF2;
4. сравнить метод Ньютона и итерационные линейные решатели только после измерения стоимости
   текущего пути;
5. оптимизировать дорогие части расчёта по результатам измерений.

## Обратная задача

Модельная обратная задача уже отделяет постоянные данные прямой задачи от калибруемых параметров.
Для полной постановки требуется:

1. определить наблюдения и пространство калибруемых граничных функций;
2. вернуть из `BasinForwardSolver` значения в точках наблюдений без обязательной записи всех
   полей;
3. согласованно обрабатывать отказ прямого расчёта внутри оптимизации;
4. проверить восстановление параметров на искусственных данных;
5. после этого переходить к данным обратной задачи организаторов.

## Подготовка к использованию

- сохранять короткую и проверяемую команду запуска;
- поддерживать описание внутреннего формата входных данных и выходных файлов;
- оставлять один основной рабочий путь без неиспользуемых сочетаний параметров;
- перед крупным ускорением фиксировать результат, точность и время исходного варианта.
