# INV-001: проверка PETSc TAO POUNDERS

Проект подключает POUNDERS через PETSc TAO для решения ограниченной задачи нелинейных наименьших
квадратов без производных.

Проверочная задача использует параметры $a$ и $b$ и невязки

$$
F_0=a-1,
\qquad
F_1=b-2,
\qquad
F_2=a+b-3.
$$

Минимум суммы квадратов равен нулю в точке $(1,2)$. Проверка создаёт объекты PETSc, выбирает
`TAOPOUNDERS`, задаёт функцию вычисления невязок, запускает `TaoSolve` и сопоставляет найденное
решение с точным.

Код собирается только при `HEAT_BUILD_MODEL_INVERSE=ON`. Проверка подтверждает подключение
библиотеки и не зависит от задачи теплопереноса.

Документация метода: [PETSc TAO POUNDERS](https://petsc.org/release/manual/tao/#pounders).
