# INV-001: Проверка PETSc TAO POUNDERS

## Цель

Проверить, что проект может собрать и запустить минимальный пример оптимизации через PETSc TAO с методом POUNDERS.

Пример должен проверять именно задачу нелинейных наименьших квадратов, поскольку в обратной задаче проекта минимизируется сумма квадратов невязок между расчётными и наблюдаемыми величинами.

## Минимальная задача

Для smoke-теста используется маленькая синтетическая задача с точно известным решением.

Пусть вектор параметров

```text
x = (a, b)
```

а вектор невязок задан как

```text
F0(a, b) = a - 1
F1(a, b) = b - 2
F2(a, b) = a + b - 3
```

Тогда задача наименьших квадратов имеет вид

```text
min ||F(a, b)||_2^2
```

и достигает нуля в точке

```text
a = 1
b = 2
```

Эта задача достаточно мала, чтобы не смешивать проверку PETSc TAO с предметной математикой проекта.

## Ожидаемый workflow PETSc

Пример должен демонстрировать минимальную последовательность работы с TAO:

- `PetscInitialize`;
- создание вектора параметров и вектора невязок;
- `TaoCreate`;
- `TaoSetType` с `TAOPOUNDERS`;
- `TaoSetSolution`;
- задание callback-функции для вычисления вектора невязок;
- `TaoSetFromOptions`;
- `TaoSolve`;
- получение найденного решения и статуса;
- освобождение PETSc-объектов;
- `PetscFinalize`.

Якобиан невязок в этом примере не задаётся, поскольку POUNDERS используется как derivative-free least squares метод.

В документации PETSc встречаются близкие названия API для задания невязок. В реализации примера нужно использовать функцию, доступную в установленной версии PETSc. Для PETSc 3.25 в manual page и примерах используется `TaoSetResidualRoutine`.

## Ожидаемый результат

Желательный результат задачи:

- пример собирается в составе CMake-проекта;
- пример запускается локально;
- в примере явно выбран метод POUNDERS;
- найденное решение близко к `(1, 2)`;
- есть простой способ повторить запуск: через CTest или отдельную документированную команду.

## Не входит в задачу

- подключение реального решателя прямой задачи;
- подбор физических параметров модели теплопереноса;
- сравнение POUNDERS с другими алгоритмами оптимизации;
- настройка производительности PETSc;
- работа с параллельным запуском нескольких прямых расчётов.
