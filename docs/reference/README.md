# Особенности расчёта

- Используется неконформная столбчатая сетка и линейная схема MPFA; нелинейная NMPFA оставлена
  для проверки результатов.
- Минимальная высота ячейки обеспечивается перераспределением толщины внутри столбца.
  Общая площадь столбца сохраняется, площади отдельных материалов могут изменяться.
- При смене эпохи переносятся температура и история зрелости. Перенос не сохраняет
  внутреннюю энергию строго; новый материал получает нулевую историю зрелости.

В постановке приведена неверная формула EASY%Ro. Используется исправленная формула из раздела
Errata статьи Sweeney и Burnham (1990).
