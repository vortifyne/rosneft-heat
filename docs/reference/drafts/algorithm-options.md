# Опции прямой и обратной задач

Обычный запуск: имя приложения, два каталога, затем опции приложения в виде `--имя значение`. Параметры PETSc с одним дефисом передаются последними. `--print-defaults` запускается отдельно, без каталогов.

## Прямая задача — `basin_forward_solver`

| Группа | Аргумент | Допустимые значения | По умолчанию | Действие |
|---|---|---|---|---|
| Ввод | `<input-dir>` | путь к каталогу | обязателен | Подготовленные входные данные бассейна. |
| Вывод | `<output-dir>` | путь к каталогу | обязателен | Каталог результатов расчёта. |
| Базальный поток | `--parameters` | путь к CSV истории потока¹ | из входных конфигураций | Заменяет заданный во входе поток пространственно постоянной историей с линейной интерполяцией по возрасту. |
| Сетка | `--dx` | > 0, м | 200 | Целевой горизонтальный шаг. Границы столбцов также зависят от узлов геометрии и смены литотипа. |
| Сетка | `--dz` | > 0, м | 50 | Целевая высота ячейки для разбиения пласта в каждом столбце. |
| Сетка | `--min-height` | > 0, м | 0.05 | Минимальная высота ячейки при построении движущейся сетки, в том числе в растущем пласте. |
| Геометрия | `--rdp-tol` | ≥ 0, м | 5 | Допуск упрощения профилей границ пластов методом Рамера–Дугласа–Пекера. 0 сохраняет исходные узлы. |
| Геометрия | `--axis-rdp-tol` | ≥ 0, м | не задан | Дополнительное упрощение только для выбора оси столбцов эпох и финальной сетки. Глубины берутся по геометрии после `--rdp-tol`. |
| Время | `--dt-ma` | > 0, млн лет | 1 | Максимальный шаг интегрирования. Шаг укорачивается до ближайшей границы эпохи или узла истории потока. |
| Пространственная схема | `--scheme` | `linear`, `nmpfa` | `linear` | Поток на внутренней вертикальной подграни. Линейная MPFA использует веса по проводимостям, консервативная NMPFA — веса по текущему решению. |
| Итерации Пикара | `--nonlinear-rtol` | 0 < r < 1 | 1e-8 | Допуск по норме нелинейной невязки относительно начальной. |
| Итерации Пикара | `--nonlinear-atol` | ≥ 0 | 1e-8 | Абсолютный допуск по норме нелинейной невязки. Достаточно выполнения одного из двух критериев. |
| Итерации Пикара | `--nonlinear-maxiter` | целое > 0 | 200 | Максимум итераций на одну нелинейную систему. |
| СЛАУ | `--linear-method` | `lu`, `gmres`, `bicgstab`, `fgmres` | `gmres` | `lu` — прямой UMFPACK. Итерационные варианты — PETSc GMRES (перезапуск 100), PETSc BiCGStab и собственный FGMRES (перезапуск 30). |
| СЛАУ | `--pc` | `none`, `ilu`, `ilu2`, `gamg`, `boomeramg` | `ilu2` | Без предобуславливателя, ILU(0), ILU(2), PETSc GAMG или hypre BoomerAMG соответственно. FGMRES поддерживает первые три, LU игнорирует выбор. |
| СЛАУ | `--pc-reuse` | `none`, `step`, `epoch` | `none` | Повторное использование предобуславливателя: выключено, в пределах шага по времени или в пределах эпохи. Действует для PETSc Krylov с предобуславливателем. Собственный FGMRES строит ILU заново. |
| СЛАУ | `--linear-rtol` | число ≥ 0 (для PETSc < 1) | 1e-8 | Относительный допуск итерационного линейного решателя. |
| СЛАУ | `--linear-atol` | число ≥ 0 | 1e-50 | Абсолютный допуск итерационного линейного решателя. |
| СЛАУ | `--linear-maxiter` | целое > 0 | 1000 | Максимум итераций на одно решение СЛАУ. |
| Вывод | `--snapshots` | `all`, `final` | `all` | Сохранить все снимки расчётных полей или только финальный. Результаты по входным конфигурациям записываются отдельно. |
| Справка | `--print-defaults` | флаг | — | Вывести численные настройки по умолчанию и выйти. |
| PETSc | `-опция [значение] …` | параметры установленной PETSc | без переопределений | Передать оставшиеся аргументы библиотеке, например `-ksp_gmres_restart 200` для PETSc GMRES. |

## Обратная задача — `basin_inverse_solver`

| Группа | Аргумент | Допустимые значения | По умолчанию | Действие |
|---|---|---|---|---|
| Ввод | `<input-dir>` | путь к каталогу | обязателен | Подготовленные данные бассейна и измерения в `observations.csv`. |
| Вывод | `<output-dir>` | путь к каталогу | обязателен | Начальные и восстановленные параметры, сравнение с измерениями, история и сводка оптимизации. |
| Старт | `--initial-q` | 50–100 мВт/м² | 75 | Одинаковый начальный поток во всех узлах. Используется при отсутствии CSV или как старт подбора в 1D. |
| Старт | `--initial-parameters` | путь к CSV истории потока¹ | узлы по эпохам | Задаёт возраста узлов и стартовые потоки вместо постоянного старта. При включённом 1D берутся узлы CSV, а значения для старта 1D задаёт `--initial-q`. |
| Старт в 1D | `--section-x` | координата сечения, м | выключен | Перед 2D-инверсией подобрать историю потока методом Гаусса–Ньютона в вертикальном сечении. Требуется хотя бы один `--section-well`. |
| Старт в 1D | `--section-well` | имя скважины, можно повторять | пусто | Выбрать скважины для подбора в 1D. Требуется `--section-x`. Основная 2D-инверсия использует все наблюдения. |
| Оптимизация | `--method` | `pounders`, `gauss-newton` | `pounders` | Метод 2D-инверсии: TAO POUNDERS без производных или Гаусс–Ньютон с якобианом из DDM. |
| Оптимизация | `--regularization` | ≥ 0 | 0 | Вес штрафа за изменение базального потока между соседними возрастами. 0 отключает штраф. |
| Остановка | `--maxiter` | целое > 0 | 10 | Лимит итераций оптимизатора. |
| Остановка | `--maxfev` | целое > 0 | 100 | Лимит вычислений целевой функции. Одна итерация может потребовать нескольких расчётов. POUNDERS может превысить лимит при построении начальной модели. |
| Остановка | `--residual-tol` | ≥ 0 | 1 | Остановка, когда модуль отклонения каждого прогноза укладывается в указанное число погрешностей измерения. 0 отключает этот критерий. |
| Сетка | `--dx` | > 0, м | 200 | Целевой горизонтальный шаг. Границы столбцов также зависят от узлов геометрии и смены литотипа. |
| Сетка | `--dz` | > 0, м | 50 | Целевая высота ячейки для разбиения пласта в каждом столбце. |
| Сетка | `--min-height` | > 0, м | 0.05 | Минимальная высота ячейки при построении движущейся сетки, в том числе в растущем пласте. |
| Геометрия | `--rdp-tol` | ≥ 0, м | 5 | Допуск упрощения профилей границ пластов методом Рамера–Дугласа–Пекера. 0 сохраняет исходные узлы. |
| Геометрия | `--axis-rdp-tol` | ≥ 0, м | не задан | Дополнительное упрощение только для выбора оси столбцов эпох и финальной сетки. Глубины берутся по геометрии после `--rdp-tol`. |
| Время | `--dt-ma` | > 0, млн лет | 1 | Максимальный шаг интегрирования. Шаг укорачивается до ближайшей границы эпохи или узла истории потока. |
| Пространственная схема | `--scheme` | `linear`, `nmpfa` | `linear` | Поток на внутренней вертикальной подграни. Линейная MPFA использует веса по проводимостям, консервативная NMPFA — веса по текущему решению. |
| Итерации Пикара | `--nonlinear-rtol` | 0 < r < 1 | 1e-8 | Допуск по норме нелинейной невязки относительно начальной. |
| Итерации Пикара | `--nonlinear-atol` | ≥ 0 | 1e-8 | Абсолютный допуск по норме нелинейной невязки. Достаточно выполнения одного из двух критериев. |
| Итерации Пикара | `--nonlinear-maxiter` | целое > 0 | 200 | Максимум итераций на одну нелинейную систему. |
| СЛАУ | `--linear-method` | `lu`, `gmres`, `bicgstab`, `fgmres` | `gmres` | `lu` — прямой UMFPACK. Итерационные варианты — PETSc GMRES (перезапуск 100), PETSc BiCGStab и собственный FGMRES (перезапуск 30). |
| СЛАУ | `--pc` | `none`, `ilu`, `ilu2`, `gamg`, `boomeramg` | `ilu2` | Без предобуславливателя, ILU(0), ILU(2), PETSc GAMG или hypre BoomerAMG соответственно. FGMRES поддерживает первые три, LU игнорирует выбор. |
| СЛАУ | `--pc-reuse` | `none`, `step`, `epoch` | `none` | Повторное использование предобуславливателя: выключено, в пределах шага по времени или в пределах эпохи. Действует для PETSc Krylov с предобуславливателем. Собственный FGMRES строит ILU заново. |
| СЛАУ | `--linear-rtol` | число ≥ 0 (для PETSc < 1) | 1e-8 | Относительный допуск итерационного линейного решателя. |
| СЛАУ | `--linear-atol` | число ≥ 0 | 1e-50 | Абсолютный допуск итерационного линейного решателя. |
| СЛАУ | `--linear-maxiter` | целое > 0 | 1000 | Максимум итераций на одно решение СЛАУ. |
| Вывод | `--save-forward` | флаг | выключен | После оптимизации повторить прямой расчёт с восстановленными параметрами и сохранить поля в `<output-dir>/forward/`. |
| Вывод | `--snapshots` | `all`, `final` | `all` | При `--save-forward` выбрать все снимки повторного расчёта или только финальный. |
| Справка | `--print-defaults` | флаг | — | Напечатать настройки прямого расчёта, начальный поток, регуляризацию и лимиты оптимизации, затем выйти. |
| POUNDERS / PETSc | `-tao_pounders_delta` | положительное число | 0.1 | Начальный радиус доверительной области. Программа также сдвигает стартовые нормированные параметры ниже верхней границы на этот запас, если они слишком близки к ней. |
| PETSc | `-опция [значение] …` | параметры установленной PETSc | без переопределений | Передать аргументы PETSc при использовании TAO POUNDERS или решателя прямой задачи с PETSc. |

¹ Заголовок CSV — `age_ma,basal_heat_flux_mw_m2`. Не менее двух узлов, возраста строго убывают от начального до конечного возраста бассейна. Потоки лежат в диапазоне 50–100 мВт/м² и не возрастают от древних узлов к молодым.

При включённом 1D-подборе регуляризация, лимиты и допуск по измерениям применяются также к этому отдельному запуску оптимизатора.
