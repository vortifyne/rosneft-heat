# Устройство алгоритма

## Обратная задача

1. Выбор начального приближения для базального теплового потока.
2. На каждой итерации — решение прямой задачи и расчёт невязок по наблюдениям температуры и отражательной способности витринита.
3. Обновление параметров методом Гаусса–Ньютона с якобианом невязок из DDM или методом POUNDERS без производных. Повтор до остановки оптимизатора.
4. Сохранение результата.

## Прямая задача

1. Чтение входных данных и построение сеток.
2. Решение стационарной задачи для начальной температуры.
3. Для каждой эпохи — интегрирование по времени. На границе эпох — перенос температуры и аррениусовских интегралов на новую сетку.
4. Сохранение итогового результата.

### Цикл по времени

1. Выбор шага, обновление геометрии и пористости.
2. Расчёт температуры на конец шага неявным методом Эйлера.
3. Обновление аррениусовских интегралов по температуре в начале и конце шага, расчёт отражательной способности витринита $R_o$.

### Решение нелинейной системы

1. Начальное приближение — температура с прошлого шага.
2. На каждой итерации Пикара — сборка матрицы $M$ и невязки $R$, решение СЛАУ $M\,\delta T=-R$ и обновление $T\leftarrow T+\delta T$.
3. Повтор до сходимости по норме невязки.

### Сборка матрицы и правой части

1. На шаге по времени фиксированы связи шаблона и геометрия ячеек и граней (длины, площади, расстояния).
2. На каждой итерации Пикара по текущему $T$ обновляются теплопроводность и объёмная теплоёмкость. Из них и геометрии собираются коэффициенты уравнений.
3. В баланс ячейки входят накопление, источники и потоки через грани с учётом граничных условий. На внутренних горизонтальных гранях поток двухточечный, на вертикальных подгранях — MPFA.

### Решение СЛАУ

В отчётных расчётах — GMRES(100) с предобуславливателем ILU(2). Переиспользование предобуславливателя настраивается отдельно, по умолчанию выключено.
