# Зрелость витринита EASY%Ro

Для каждой материальной ячейки и каждой реакции накапливается интеграл

$$
I_i(t)
=
\int_{t_{\mathrm{dep}}}^{t}
A\exp\left(-\frac{E_i}{R_gT(\tau)}\right)d\tau.
$$

Здесь $A$ — предэкспоненциальный множитель в с$^{-1}$, $E_i$ — энергия активации в Дж/моль,
$R_g$ — газовая постоянная в Дж/(моль·К), $T$ — абсолютная температура.

Степень превращения вычисляется по формуле

$$
F
=
\sum_i f_i\left(1-\exp(-I_i)\right),
$$

а отражательная способность — по формуле

$$
R_o=\exp(-1{,}6+3{,}7F).
$$

В данных содержатся 20 коэффициентов $f_i$ с суммой $0{,}85$. Они не нормируются, поэтому

$$
F(0)=0,
\qquad
F_{\max}=0{,}85.
$$

Это соответствует исправлению к исходной модели: J. J. Sweeney, A. K. Burnham, “Evaluation of
a Simple Model of Vitrinite Reflectance Based on Chemical Kinetics”, *AAPG Bulletin*, 74(10),
1990, 1559–1570,
[DOI: 10.1306/0C9B251F-1710-11D7-8645000102C1865D](https://doi.org/10.1306/0C9B251F-1710-11D7-8645000102C1865D).

Запись $F=1-\sum_i f_i\exp(-I_i)$ из постановки не используется: при сумме коэффициентов
$0{,}85$ она даёт ненулевое превращение в начальный момент.

## Интегрирование

Между двумя принятыми температурными состояниями температура считается линейной по времени.
Временной шаг делится на 16 равных частей, и на каждой части интеграл вычисляется двухточечной
формулой Гаусса. Повторно решать температурную задачу для этого не требуется.

Интегралы обновляются только после принятого температурного шага. При движении сетки они остаются
связанными с материальными ячейками, а при перестроении переносятся вместе с температурой. В новом
материале интегралы равны нулю.

Поле $R_o$ записывается в каждый сохраняемый файл VTU. Значение в конечный момент является
результатом прямой задачи наряду с температурной историей.
