# Переход между геологическими эпохами

В конце эпохи старая сетка достигает конечной конфигурации. Затем в тот же момент времени строится
сетка следующей эпохи. Перестроение не увеличивает физическое время.

Разбиение по горизонтали и число рядов каждого слоя заранее согласованы для всей используемой
последовательности конфигураций. Поэтому у сохранившейся части материала ячейки на двух сетках
имеют одинаковое расположение и устойчивые идентификаторы слоя, столбца и ряда.

Температура сначала переносится по физическому положению во всей области, существовавшей до перестроения. В старой ячейке восстанавливается линейное поле, а полученное значение ограничивается диапазоном этой ячейки и её соседей.

При исчезновении части слоя старая сетка перед переходом сохраняет малую положительную толщину,
описанную в [соглашении о движении](moving-mesh-epoch.md). После построения точной конечной сетки
температура переносится из того же слоя с учётом горизонтальной координаты и относительной глубины.
Поиск ближайшей ячейки того же слоя применяется только там, где обычная реконструкция не находит
ячейку-источник. Это правило не применяется к новому материалу.

Отдельное начальное распределение задаётся только на действительно добавившейся площади. Оно линейно соединяет поверхностную температуру с температурой прежнего материала под контактом.

Литотип и пористость берутся из новой конфигурации и не переносятся со старой сетки. История BDF1 сбрасывается, поскольку размеры и номера ячеек изменились.

Возможная погрешность переноса входит в единый
[глобальный баланс энергии](global-energy-balance.md). Отдельный показатель для перехода не
используется. Консервативный перенос остаётся последующим улучшением, если глобальный баланс или
проверка на точном решении покажут его необходимость.
