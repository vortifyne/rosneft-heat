# Полный расчёт геологической истории

Расчёт получает упорядоченный список конфигураций от древнейшей к современной и проходит каждую
соседнюю пару как одну эпоху. Значения возрастов не задаются в коде. По умолчанию используются все
конфигурации; ограничение их числа предназначено только для коротких проверочных запусков.

Внутри эпохи геометрия, пористость и граничные условия линейно меняются по времени. Температура
относится к движущейся материальной ячейке, поэтому отдельное конвективное слагаемое не добавляется.
Шаг BDF1 сокращается только для точного попадания на конец эпохи. Несошедшийся шаг не принимается и
останавливает расчёт.

Послойное перемещение вершин используется, пока оно сохраняет положительную площадь каждой ячейки.
Если прямолинейная грань не может воспроизвести сильный изгиб границы слоя, перемещение смешивается с
монотонным перемещением по общей глубине существующего материала. Если этого недостаточно, величина
перемещения уменьшается. Это сохраняет связность и положительные площади, но сетка перед
перестроением может не совпасть с новой конфигурацией точно.

На границе эпохи строится новая сетка полной следующей конфигурации. Температура и интегралы
EASY%Ro сначала переносятся по физическому положению. Для прежнего материала, который не удалось
сопоставить по положению из-за ограниченной деформации, используется тот же слой и ближайшая точка по
горизонтальной координате и относительной глубине. Только действительно новая площадь получает
начальную температуру и нулевые интегралы EASY%Ro.

Каждый запуск создаёт общий временной ряд PVD, файлы VTU, таблицу сохранённых состояний, таблицы эпох
и перестроений и итоговую строку со временем, числами шагов и итераций, размерами сеток и наибольшей
относительной несбалансированностью энергии при переносе.

Перенос пока не является консервативным. В проверочных расчётах наибольшая относительная
несбалансированность достигла 7,8% для `data1` и 23,5% для `data2`. Поэтому консервативный перенос
остаётся обязательным последующим улучшением перед фиксацией расчётной базы.
