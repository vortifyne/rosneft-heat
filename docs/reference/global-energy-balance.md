# Глобальный баланс энергии

Вся расчётная область рассматривается как один контрольный объём. Внутренние потоки сокращаются
попарно, через боковые границы поток равен нулю, нижняя граница подводит тепло, верхняя отводит
его, а радиогенное тепловыделение добавляет тепло внутри области.

Внутренняя энергия относительно опорной температуры определяется как

$$
H=\sum_K |K|\int_{T_{\mathrm{ref}}}^{T_K}(\rho c)(\theta,\phi_K)\,d\theta.
$$

После каждого шага к накопленному дисбалансу добавляется

$$
\Delta B
=
H^n-H^{n-1}
+\Delta t\left(Q_{\mathrm{top}}^n-Q_{\mathrm{bottom}}^n-Q_A^n\right).
$$

Используется то же приближение первого порядка по времени, что и в BDF1. При появлении нового
материала его начальная энергия считается физическим приходом и не включается в дисбаланс. При
перестроении сетки без изменения времени учитывается только изменение энергии уже существовавшего
материала.

Единственный выводимый показатель равен

$$
\varepsilon_E
=
\frac{|B|}{\max\left(|E_{\mathrm{bottom}}|,1\right)},
$$

где $E_{\mathrm{bottom}}$ — накопленный приток энергии через нижнюю границу. Его временной ряд
сохраняется в `energy-balance.csv`, итоговое значение — в `summary.csv`.

Для полного пробного расчёта `data1` с размером ячейки 50 м и шагом 1 млн лет получено
$\varepsilon_E\approx3{,}28\cdot10^{-4}$. Переход 5→0 млн лет изменяет эту величину примерно на
$5\cdot10^{-9}$; основной вклад накапливается на временных шагах.
