# Оценка обусловленности линейной системы

По отдельному запросу решатель оценивает обусловленность каждой матрицы метода Пикара. После
разложения UMFPACK вычисляется отношение наибольшего и наименьшего по модулю диагональных элементов
верхнего треугольного множителя:

$$
\widehat\kappa=\frac{\max_i |U_{ii}|}{\min_i |U_{ii}|}.
$$

Это грубая оценка, а не число обусловленности матрицы в заданной норме. Она предназначена для
сравнения расчётов одной задачи и обнаружения ухудшения матрицы при деформации сетки. Обычный
расчёт эту величину не вычисляет.

Для `data1`, размера ячейки 50 м и шага 1 млн лет получено:

- большую часть истории оценка находится примерно между 80 и 475;
- при толщине исчезающего слоя не меньше 0,5 м максимум составляет примерно $1{,}74\cdot10^4$;
- при одном относительном пороге 0,1% максимум составляет примерно $1{,}01\cdot10^6$.

Абсолютный порог 0,5 м уменьшает максимальную оценку почти в 60 раз. Его влияние на конечную
температуру относительно гораздо более тонкого слоя не превышает 0,135 K, среднеквадратичное
различие равно 0,070 K.
