# Проверка прямого решателя

Проверки разделены по уровню: самостоятельные модули проверяются малыми задачами, численные
порядки — специально построенными решениями, а полный ход расчёта — на `data1` и `data2`.
Конкретные результаты отдельных запусков хранятся вне справочной документации.

## Автоматические проверки

Команда

```bash
make docker-test
```

проверяет линейную алгебру, временную схему, нелинейный метод, пространственную дискретизацию,
теплофизические свойства, EASY%Ro, построение сетки, перенос полей и повторное использование
класса `BasinForwardSolver`.

Значения теплофизических свойств сопоставляются с функциями из переданного организаторами файла
`basin_data.py` для всех литотипов доступных наборов данных.

## Пространственный порядок

На прямоугольнике $0\le x\le4$, $0\le z\le2$ используется стационарное решение

$$
T(x,z)
=
300
+
20\cos\left(\frac{\pi x}{4}\right)
\sin\left(\frac{\pi z}{4}\right).
$$

При постоянной теплопроводности $\lambda$ объёмный источник вычисляется как

$$
A=-\lambda\Delta T.
$$

На верхней границе задаётся точная температура, снизу и по бокам — нулевой поток. При
последовательном уменьшении размера ячейки проверяется второй порядок ошибки температуры.

## Временной порядок

Для BDF1 используется затухающая тепловая мода

$$
T(z,t)
=
300
+
10\exp\left(
-\frac{\lambda}{\rho c}
\left(\frac{\pi}{2}\right)^2t
\right)
\sin\left(\frac{\pi z}{2}\right).
$$

Пространственная ошибка делается существенно меньше временной. При последовательном уменьшении
шага проверяется первый порядок BDF1.

## Перенос поля

Гладкое поле

$$
T(x,z)
=
300
+
15\cos\left(\frac{\pi x}{4}\right)
\sin\left(\frac{\pi z}{2}\right)
$$

переносится между сетками одной области. Проверяются сохранение постоянного поля, отсутствие
новых экстремумов и уменьшение ошибки при сгущении сеток.

## Полный расчёт

`data1` служит основным набором для проверки решения и влияния шагов по пространству и времени.
`data2` проверяет чтение более сложных данных, меняющиеся граничные условия и стоимость полного
расчёта.

Для обоих наборов проверяются:

- завершение всех входных конфигураций;
- сходимость метода Пикара на каждом временном шаге;
- положительная площадь всех ячеек;
- отсутствие выбросов температуры и EASY%Ro;
- глобальный баланс энергии;
- возможность открыть временной ряд в ParaView.

Результаты разных сеток сопоставляются в одинаковых физических точках. Для оценки ошибки без
эталонного решения используется правило Рунге только на последовательности согласованно
сгущающихся расчётов.
